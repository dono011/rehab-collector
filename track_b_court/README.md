# 트랙 B — 법원 공고 회생업체 수집기

법원 공고에서 회생·파산·매각 공고를 수집합니다.
**트랙 A(DART)가 못 잡는 비상장 중소기업**이 대상이며, 전기공사업 회생은 여기에 다수 있을 것으로 봅니다.

---

## ✅ 2026-08-20 실제 구조 확인 완료

VPS 정찰로 대상 사이트를 확인하고 **실제 주소·파라미터·표 구조를 확정**했습니다.

```
주소   https://www.scourt.go.kr/portal/notice/mainfo/MaNoticeList.work
파라미터 business(업종) / bub_cd(법원) / pageIndex / pageSize
표구조  번호 | 관할법원 | 업종 | 회사 | 작성일
```

| 확인 항목 | 결과 |
|---|---|
| robots.txt (`urllib.robotparser` 기계 판정) | 🟢 **허용** |
| HTTP 응답 | 🟢 200 |
| 렌더링 | 🟢 서버 렌더링 — **Selenium 불필요** |
| GET 파라미터 필터 | 🟢 동작 (`business=08` 검증) |
| 회사명 | 🟢 **별도 칼럼 제공** — 추측 불필요 |

바로 실행하시면 됩니다.

```bash
pip install requests beautifulsoup4 openpyxl --break-system-packages
cd track_b_court
python3 collect_court.py --check     # 접근 확인
python3 collect_court.py             # 수집
python3 collect_court.py --codes     # 업종·법원 코드표
```

---

## ⚠️ 가장 중요한 주의 — 업종을 좁히면 놓칩니다

법원의 업종 분류가 **느슨하게 운영되고 있습니다.** 실제 목록에서:

```
세아STX엔테크 주식회사   → 업종 "기타"   (실제로는 플랜트 엔지니어링)
㈜이노피아테크          → 업종 "기타"   (실제로는 전자·통신)
```

그래서 **기본값은 "전체 수집"** 입니다. `--business 08` 로 좁히면 "기타"에 묻힌 전기 업체를 통째로 놓칩니다.

수집한 뒤 회사명 키워드로 한 번 더 거르는 **이중 방식**을 씁니다.

## 참고 — 정찰 도구 (probe.py)

구조는 이미 확정됐지만, 나중에 사이트가 개편되면 다시 쓸 수 있습니다.

수동 curl을 대신하는 도구입니다. 이것만 돌리면 필요한 정보가 리포트로 정리됩니다.

```bash
pip install requests beautifulsoup4 openpyxl --break-system-packages
cd track_b_court
python3 probe.py
```

확인하는 것:

| 항목 | 판단 |
|---|---|
| robots.txt | 크롤링 허용 여부 |
| HTTP 응답 | 접근 가능 (200/403/404) |
| 렌더링 방식 | HTML에 데이터가 있는가 / JS로 그리는가 |
| **사건번호 존재** | `2026회합163` 패턴이 실제로 보이는가 ← **가장 결정적** |
| 표 구조 | 파싱 가능한 `<table>`/`<ul>` |

결과는 `output/probe_report.txt` 에 저장됩니다. **이 파일 내용을 그대로 전달하면 다음 단계로 넘어갑니다.**

### 결과 해석

| 리포트 내용 | 의미 | 다음 |
|---|---|---|
| 🟢 `사건번호 N건 발견` | 바로 파싱 가능 | `--save-html` 로 재실행 → 크롤러 완성 |
| 🔴 `본문이 거의 비어 있음` | JS 렌더링 | Selenium 필요 (+2~4일) |
| 🔴 `HTTP 403` | 봇 차단 | 헤더/세션 조정 |
| ⚪ `HTTP 404` | 주소 변경됨 | 실제 주소 재확인 |
| 🔴 `Disallow: /` | 크롤링 금지 | **중단.** 합법 경로만 사용 |

파서 개발용 HTML까지 받으려면:

```bash
python3 probe.py --save-html      # output/html/ 에 저장
```

## 2단계 — 수집 (collect_court.py)

```bash
python3 collect_court.py --check       # 접근·파싱 가능 여부만
python3 collect_court.py               # 수집 (사이트당 3페이지)
python3 collect_court.py --pages 10    # 10페이지까지
python3 collect_court.py --all         # 이미 본 건도 포함
```

### 오프라인 테스트

저장된 HTML로 파서만 시험할 수 있습니다. 네트워크가 필요 없습니다.

```bash
python3 collect_court.py --html output/html/저장된파일.html
```

## 전기 관련도 판정 — 정확도 한계를 알아두세요

트랙 A는 DART **업종코드**를 쓰지만, 비상장사는 업종 정보가 없어 **회사명 키워드**로 추정합니다.

| 키워드 | 관련도 |
|---|---|
| 전기공사, 전기설비, 전설 | **3** |
| 전기, 전력, 배전, 송전, 변전, 계전, electric | 2 |
| 파워, 에너지, 발전, 전공, power | 1 |

관련도 2 이상이 엑셀에서 노란색으로 강조됩니다.

> ⚠️ **회사명 기반 추정이라 오탐·누락이 있습니다.**
> - 오탐: "전기" 들어가지만 전기공사업이 아닌 곳 (제조·도매 등)
> - 누락: 이름에 전기가 없는 전기공사업체
>
> **최종 확인은 반드시 한국전기공사협회(02-2670-5000) 조회로 하세요.**

## 법적 준수

크롤러에 다음이 구현되어 있습니다:

- ✅ **robots.txt 확인** — 금지 경로면 해당 사이트를 자동으로 건너뜁니다
- ✅ **요청 간격 1.2초** — 서버 부담 최소화
- ✅ **공개 공고만** 수집

### 하지 않는 것

- ❌ **민간 집계 사이트 크롤링** — 로집사 등은 기술적으로 더 쉽지만 **저작권법상 DB제작자 권리 침해** 소지가 있어 대상에서 제외했습니다
- ❌ **개인정보 수집** — 공고에 기재된 법인 정보만 다룹니다

## 문제 해결

| 증상 | 해결 |
|---|---|
| `수집된 공고가 없습니다` | 사이트가 개편된 것. `probe.py` 실행 후 알려주세요 |
| `robots.txt가 이 경로를 금지함` | **크롤링 중단.** 다른 경로를 찾아야 합니다 |
| `HTTP 403` | 봇 차단. `probe.py` 결과를 보내주시면 헤더 조정하겠습니다 |
| 회사명이 이상하게 추출됨 | 해당 공고 제목을 알려주시면 `parsers.py` 패턴을 보강합니다 |
| `ModuleNotFoundError: bs4` | `pip install beautifulsoup4 --break-system-packages` |
