# 트랙 A — DART 회생공시 자동 수집기

금융감독원 전자공시(DART) **공식 OpenAPI**로 회생 관련 공시를 매일 자동 수집해 엑셀로 저장합니다.

크롤링이 아니라 API라서 **robots.txt 위반·IP 차단·법적 리스크가 없습니다.**

---

## 이 도구가 커버하는 범위

| | 대상 | 커버 |
|---|---|---|
| ✅ | 상장사 (코스피·코스닥·코넥스) | 100% |
| ✅ | 사업보고서 제출 대상 비상장법인 | 상당 부분 |
| ❌ | 그 외 비상장 중소기업 | **트랙 B(법원 공고)가 필요** |

> 전기공사업 회생은 비상장 중소기업이 다수일 것으로 보입니다.
> 트랙 A는 **"지금 당장, 리스크 없이 되는 절반"**이고, 나머지는 트랙 B에서 다룹니다.

---

## 3분 설치

### 1단계 — API 키 발급 (무료, 1분)

1. https://opendart.fss.or.kr 접속
2. 상단 **인증키 신청/관리** → **인증키 신청**
3. 이메일 인증하면 40자리 키가 즉시 발급됩니다
4. 일 20,000건까지 무료

### 2단계 — 라이브러리 설치

```bash
pip install requests openpyxl --break-system-packages
```

### 3단계 — 키 등록

```bash
export DART_API_KEY="발급받은40자리키"
```

매번 입력하기 번거로우면 파일로 저장해도 됩니다:

```bash
echo "발급받은40자리키" > dart_key.txt
```

### 4단계 — 연결 확인

```bash
python3 collect_rehab.py --test
```

정상이면 이렇게 나옵니다:

```
✅ 정상 — 테스트 조회 결과:
   회사명   : (주)광명전기
   대표자   : 조광식
   사업자번호: 1348104007
   전화     : 031-494-0720
```

## 실행

```bash
python3 collect_rehab.py                      # 최근 30일
python3 collect_rehab.py --days 90            # 최근 90일

python3 collect_rehab.py --no-financials      # 재무조회 생략 (3배 빠름)
```

## 결과물

`output/회생신청_정보_YYYYMMDD.xlsx` — 원 기획서의 16개 항목 그대로

| 항목 | 출처 | 상태 |
|---|---|---|
| 수집일자 | 자동 생성 | ✅ |
| 회사명 | DART 기업개황 | ✅ |
| **사업자번호** | DART `bizr_no` | ✅ |
| **대표자명** | DART `ceo_nm` | ✅ |
| 관할법원 | 공시 원문 | ⚠️ 링크 제공 |
| 사건번호 | 공시 원문 | ⚠️ 링크 제공 |
| 신청일 / 결정일 | 공시 접수일 | ✅ |
| 사건상태 | 공시 제목에서 추정 | ✅ |
| 면허/업종 | DART 업종코드 | ⚠️ 추정 |
| 자본금 | DART 사업보고서 | ✅ |
| 채무액 | DART 부채총계 | ⚠️ 근사치 |
| **소재지** | DART `adres` | ✅ |
| **전화번호** | DART `phn_no` | ✅ |
| 데이터출처 | 접수번호 | ✅ |
| 비고 | 관련도 + 원문 URL | ✅ |

**굵은 항목은 앞선 검토에서 "자동수집 불가"로 분류했던 것들입니다.** DART가 직접 제공한다는 걸 확인해 가능으로 바뀌었습니다.

### 엑셀 기능
- 전기 관련 업체는 **노란색 강조**
- 관련도 높은 순 정렬
- 자동필터 + 첫 행 고정

### ⚠️ 값을 그대로 믿으면 안 되는 항목

- **채무액** = 재무제표 부채총계입니다. 회생채권 확정액이 아니고, 우발부채(PF 지급보증 등)는 빠져 있습니다. 실제 규모는 훨씬 클 수 있습니다.
- **면허/업종** = 한국표준산업분류 코드 기반 추정입니다. **전기공사업 등록 보유 여부는 한국전기공사협회 확인이 필요합니다.**
  - 예: 광명전기는 `28123`(배전반 제조업)이지 `42201`(일반 전기공사업)이 아닙니다.
- **관할법원 / 사건번호** = 공시 본문에 있으나 파싱하지 않았습니다. 비고란 원문 링크를 클릭하면 확인됩니다.

### 업종 관련도 기준

| 코드 | 분류 | 관련도 |
|---|---|---|
| `422xx` | 전기·통신공사업 | **3** (최우선) |
| `28xxx` | 전기장비 제조업 | 2 |
| `351xx` | 전기업(발전·송배전) | 2 |
| `261xx` | 반도체·전자부품 | 1 |
| 그 외 | | 0 |

관련도 2 이상만 엑셀에서 강조되고 콘솔에 요약됩니다.

## 매일 자동 실행

### Linux / macOS (crontab)

```bash
crontab -e
```

아래 한 줄 추가 (매일 새벽 2시):

```
0 2 * * * cd ~/track_a_dart && DART_API_KEY="키" /usr/bin/python3 collect_rehab.py --days 7 >> output/cron.log 2>&1
```

> `--days 7`을 쓰는 이유: 매일 도는데 30일치를 매번 조회할 필요가 없습니다. 중복은 `seen.json`이 자동으로 걸러냅니다.

### Windows (작업 스케줄러)

1. 작업 스케줄러 → **기본 작업 만들기**
2. 이름: `회생정보_자동수집`
3. 트리거: 매일 새벽 2시
4. 동작: 프로그램 시작
   - 프로그램: `python`
   - 인수: `collect_rehab.py --days 7`
   - 시작 위치: 스크립트 폴더 경로

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| `DART API 키가 없습니다` | `export DART_API_KEY="키"` 또는 `dart_key.txt` 생성 |
| `등록되지 않은 키입니다` | 키 오타 확인. 40자리 전체를 복사했는지 확인 |
| `접근할 수 없는 IP입니다` | DART 사이트에서 이 서버 IP를 등록 |
| `요청 제한을 초과했습니다` | 일 20,000건 초과. 내일 재시도하거나 `--no-financials` 사용 |
| `ModuleNotFoundError` | `pip install requests openpyxl --break-system-packages` |
| 네트워크 오류 | 자동으로 3회 재시도(2·4·8초)합니다. 계속되면 VPS 방화벽 확인 |
| 결과가 0건 | 정상일 수 있습니다. `--days 90`으로 기간을 늘려보세요 |
